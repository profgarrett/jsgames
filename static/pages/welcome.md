# Welcome

This page is served from an in-repo markdown file and rendered as HTML in the browser.

Add new pages by dropping a `.md` file into `static/pages/`. The first `#` heading
becomes the page title shown in the index.

## Formatting is supported

You can use **bold**, *italic*, and `inline code`, plus links like
[the course site](https://profgarrett.github.io/course_model/).

### Lists

- Bullet lists
- With multiple items

1. Numbered lists
2. Work too
