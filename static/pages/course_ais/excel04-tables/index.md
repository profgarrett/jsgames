# Tables

This module introduces the concept of tables in Excel

**Outcomes**

After completing this material, students should be able to:

* Create and format tables to organize data.
* Use structured references to refer to table data in formulas.
* Sort, filter, and format a table
* Add/remove columns and rows in a table
* Use XLookup to pull data from another table
* Use a PivotTable to summarize data from a table
