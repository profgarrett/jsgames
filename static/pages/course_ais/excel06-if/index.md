# If

This module introduces the concept of the IF function in Excel

**Outcomes**

After completing this material, students should be able to:

- Describe how to create a conditional statement that results in TRUE or FALSE
- Compare strings and numbers
- Use the IF function to create conditional formulas in Excel
- Use AND and OR functions to create more complex conditional formulas
- Use the result of an IF function for a calculation
