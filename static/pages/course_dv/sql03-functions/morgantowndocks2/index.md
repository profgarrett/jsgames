# Problem: Fix issues with Morgantown's weather data

We will use concepts from [SQL 3](./../) to fix some issues with Morgantown's weather data.
## Outcome

- Practice functions and data type concepts introduced in SQL3.
## Process
- Download the [db file](ghcn_daily_morgantowndocks2.db)  
- Download the [sql file](problem.sql) 
- Move both files into a new folder.
- Open *DB Browser* and choose *File* / *Open DB*
- Go to the execute SQL tab. Then, use the 2nd button from the left to open the SQL file
- Start answering questions!
