# Problem: Create a summary of Morgantown's weather data

We will use concepts from [SQL 4](./../) to view summary weather data
## Outcome

- Practice aggregation functions

## Process
- Download the [db file](ghcn_daily_morgantowndocks3.db)  
- Download the [sql file](problem.sql) 
- Move both files into a new folder.
- Open *DB Browser* and choose *File* / *Open DB*
- Go to the execute SQL tab. Then, use the 2nd button from the left to open the SQL file
- Start answering questions!
