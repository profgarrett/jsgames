# Problem: Why use a database instead of Excel?

## Outcome

- Identify reasons to use a relational database instead of Excel

## Problem

ABC Consulting has been asked to figure out why a new initiative failed to deliver. They have traced the underlying problem to a sales initiative for Product D underperforming. This dataset was used to justify a decision to move all marketing dollars from A, B, and C to D.

What issues can you find that suggest this initiative was a mistake?

## Process
- Download the [whydb.csv file](whydb.csv)  
- Open the file in Excel
- Try to find at least five of the six errors.
