# Working with files

Managing your folders and files is a key skill. This page walks you through the major things you should know to work successfully on your computer.

**Outcomes**:

- Organize your files into folders
- Avoid problems with OneDrive
- Move files between folders
- Show file extensions
- Create a screenshot


## Organizing your files

When you save a file, it goes into the hard drive on your computer. This hard drive (called the `C:\` on Windows) organizes files into certain locations, called folders.

All modern systems store your files in several folders:

- `Downloads`: this is supposed to be temporary spot for files downloaded by Safari, Chrome, or Edge.
- `Desktop`: files/folders visible on your desktop
- `Documents`: where you should store your long-term files

Here is a quick guide for organizing your files, slightly more focused on the Mac. [YouTube](https://www.youtube.com/watch?v=gfx7G4NQQMg)


### Issues with OneDrive

One wrinkle is that Windows often uses OneDrive. OneDrive is an online service that syncs your local files with servers on the Internet. Files are typically still stored on your computer, but are regularly uploaded. So, if you have OneDrive turned on, typically the OneDrive Downloads/Desktop/Documents is the same as the location on your hard drive.

*If you use OneDrive*, be careful during exams! If you save a file to OneDrive, and your Internet connection is spotty, your file may not save correctly. So, during exams, I suggest saving files to your local hard drive. Do this by choosing Save As and selecting a location on your hard drive (i.e., navigate in File Explorer to local computer, and selecting the correct folder. Do not save directly to OneDrive. 

*If you submit an empty or unsaved file for an assignment or exam, you will receive a zero.* If you're not sure, then upload your file, download it, and open it. 


## Making folders

You should have a folder for our class. Then, create a folder for each week or major project. Store your files inside of this folder.

*For Windows*: Right-click in a folder, and choose `New folder` (or press `Control+Shift+N`). [YouTube](https://www.youtube.com/watch?v=Amd6V-ERLO8)

*For Mac*: Right-click in a folder, and choose `New Folder`. [YouTube](https://www.youtube.com/watch?v=xPVOaFmQ7_s)


## Moving files

Avoid modifying any files in your `Downloads` folder. Instead, download them, and then copy them to the appropriate folder.

*For Windows*: Guide to using File Explorer on Windows. [YouTube](https://www.youtube.com/watch?v=hXLpEG3IX-A)

*For Mac*:  Right-click on a file, select copy, go to the new place, and click paste.  Or, move a file by opening a separate `Finder` window, and dragging/dropping your files. [YouTube](https://www.youtube.com/watch?v=gFKJpkpDcwo)

I suggest disabling the Force touch feature:

- Use the Apple menu to open `System Settings`
- Click `Trackpad`, the `Point & Click` tab
- Turn off `Force click and haptic feedback` 


## Handling Zip files

A zip file is a compressed file that contains one or more files. You can think of it as a folder that has been compressed into a single file. 

On Windows, double-clicking a zip file will open it in a temporary folder. These can not be used as a datasource for Tableau or PowerBI. **You need to extract the files before you can use them.**

*For Windows*: Right-click the zip file and select `Extract All`. 

*For Mac*: Double-click the zip file to unzip it. 


## File Extensions

One more thing that would be helpful in our class is to turn on file extensions. This will tell you the hidden information that lives in every file's name. So, when you save a Word document as `my stuff`, it actually is saved as `my stuff.docx`. The `.docx` tells the computer to open the file in Word.

As we work with more complex files, you will find that you can not just click on a file to open it in the right program. Instead, get in the habit of opening a program first. Then, inside of the program, open the file (usually by going to the file menu and choosing open).

*For Windows:*

- Open File Explorer
- Open View menu
- Show submenu
- File Name Extensions

*For Mac:*

- Open Finder
- Click on the Finder menu (on the top of your screen)
- Open Settings
- Advanced tab
- Check the box that says to *show all filename extensions*


## File Naming

When you save a file, give it a name that is descriptive. Avoid using spaces or special characters. Use underscores or dashes instead of spaces. For example, instead of `my stuff.docx`, use `my_stuff.docx` or `my-stuff.docx`.

For larger projects, you should create multiple versions of your file. Do this by adding a version number to the end of your file name. For example, `my_stuff_v1.docx`, `my_stuff_v2.docx`, etc. This will help you keep track of your progress and avoid losing work.


## Save your files in progress

None of the programs we use auto-save like Google Docs. So, you need to save your work frequently. I suggest saving your work every 5-10 minutes. If you are working on a large project, save your work every time you make a significant change.

This is especially important during exams. If you do not save your work, and your computer crashes, you will lose all of your work. So, save early and often.


## Create a screenshot

When you take a screenshot, you capture what is on your screen as an image file. This is useful for assignments, exams, or sharing information with others.

This [website](https://www.take-a-screenshot.org/) has a good summary of how to take screenshots on different devices. Below is a quick summary.

*For Windows:*

- Search for "Snipping Tool" in the Start menu, open it, and click "New" to select the area you want to capture. 
- Or, press the keyboard shortcut `Windows key + Shift + S` to copy the captured area to your clipboard. You can then paste it into a document or image editor. Windows 11 also auto-saves to `Pictures\Screenshots`.
- Save the screenshot to your desired location from the Snipping Tool interface.

*For Mac:*

- Press `Command+Shift+4`. This will change your cursor to a crosshair. 
- Click and drag to select the area you want to capture. 
- Release the mouse button to save the screenshot to your desktop.
